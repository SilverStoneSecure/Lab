# Project Summary

A portable Node.js + Fastify homelab dashboard template backed by SQLite, with login-protected admin editing for cards, inventory, and site copy.
Ships with Docker Compose support, a seedable "Lab" snapshot, and configurable card layouts (tiles, rail, gallery) for organizing LAN/WAN services, devices, contacts, and media.
